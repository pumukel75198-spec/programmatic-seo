# Sendinblue Email API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Sendinblue
- **Category:** Communication
- **Endpoint:** `https://api.sendinblue.com/v3`
- **Method:** `GET`
- **Auth:** `bearer` via `SENDINBLUE_API_KEY`
- **Docs:** https://developers.sendinblue.com/docs

## Quick start

```bash
# 1) Inspect the request (no network)
python3 sendinblue-email-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 sendinblue-email-api.py --smoke

# 3) Send a real request
export SENDINBLUE_API_KEY="your-key"
python3 sendinblue-email-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
