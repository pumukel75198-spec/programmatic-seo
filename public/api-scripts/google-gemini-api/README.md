# Google Gemini API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Google
- **Category:** AI & Multimodal
- **Endpoint:** `https://generativelanguage.googleapis.com/v1beta`
- **Method:** `GET`
- **Auth:** `query` via `GOOGLE_API_KEY`
- **Docs:** https://ai.google.dev/gemini-api/docs

## Quick start

```bash
# 1) Inspect the request (no network)
python3 google-gemini-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 google-gemini-api.py --smoke

# 3) Send a real request
export GOOGLE_API_KEY="your-key"
python3 google-gemini-api.py --live --data '{"example":"value"}'
```

- Requires Python 3.8+ and only uses the standard library.
