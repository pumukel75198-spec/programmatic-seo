# Discord Bot API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Discord
- **Category:** Community & Messaging
- **Endpoint:** `https://discord.com/api/v10/channels/{channel.id}/messages`
- **Method:** `POST`
- **Auth:** `bot` via `DISCORD_BOT_TOKEN`
- **Docs:** https://discord.com/developers/docs/reference

## Quick start

```bash
# 1) Inspect the request (no network)
python3 discord-bot-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 discord-bot-api.py --smoke

# 3) Send a real request
export DISCORD_BOT_TOKEN="your-key"
python3 discord-bot-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
