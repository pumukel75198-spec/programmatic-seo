# Weaviate Vector API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Weaviate
- **Category:** Vector Database
- **Endpoint:** `https://{cluster}.weaviate.network/v1`
- **Method:** `GET`
- **Auth:** `bearer` via `WEAVIATE_API_KEY`
- **Docs:** https://weaviate.io

## Quick start

```bash
# 1) Inspect the request (no network)
python3 weaviate-vector-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 weaviate-vector-api.py --smoke

# 3) Send a real request
export WEAVIATE_API_KEY="your-key"
python3 weaviate-vector-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
