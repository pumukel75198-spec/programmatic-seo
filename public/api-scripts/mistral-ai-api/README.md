# Mistral AI API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Mistral AI
- **Category:** AI & LLM
- **Endpoint:** `https://api.mistral.ai/v1/models`
- **Method:** `GET`
- **Auth:** `bearer` via `MISTRAL_API_KEY`
- **Docs:** https://mistral.ai

## Quick start

```bash
# 1) Inspect the request (no network)
python3 mistral-ai-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 mistral-ai-api.py --smoke

# 3) Send a real request
export MISTRAL_API_KEY="your-key"
python3 mistral-ai-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
