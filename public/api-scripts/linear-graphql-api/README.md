# Linear GraphQL API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Linear
- **Category:** Project Management
- **Endpoint:** `https://api.linear.app/graphql`
- **Method:** `POST`
- **Auth:** `bearer` via `LINEAR_API_KEY`
- **Docs:** https://developers.linear.app/docs/graphql/working-with-the-graphql-api

## Quick start

```bash
# 1) Inspect the request (no network)
python3 linear-graphql-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 linear-graphql-api.py --smoke

# 3) Send a real request
export LINEAR_API_KEY="your-key"
python3 linear-graphql-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
