# Airtable API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Airtable
- **Category:** Databases
- **Endpoint:** `https://api.airtable.com/v0`
- **Method:** `GET`
- **Auth:** `bearer` via `AIRTABLE_API_KEY`
- **Docs:** https://airtable.com/developers/web/api

## Quick start

```bash
# 1) Inspect the request (no network)
python3 airtable-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 airtable-api.py --smoke

# 3) Send a real request
export AIRTABLE_API_KEY="your-key"
python3 airtable-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
