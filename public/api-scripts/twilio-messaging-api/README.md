# Twilio Messaging API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Twilio
- **Category:** Communication
- **Endpoint:** `https://api.twilio.com/2010-04-01`
- **Method:** `GET`
- **Auth:** `basic` via `TWILIO_AUTH`
- **Docs:** https://www.twilio.com/docs/messaging

## Quick start

```bash
# 1) Inspect the request (no network)
python3 twilio-messaging-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 twilio-messaging-api.py --smoke

# 3) Send a real request
export TWILIO_AUTH="your-key"
python3 twilio-messaging-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- Set TWILIO_AUTH to ACCOUNT_SID:AUTH_TOKEN (Basic auth).
