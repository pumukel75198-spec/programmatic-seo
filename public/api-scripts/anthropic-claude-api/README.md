# Anthropic Claude API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Anthropic
- **Category:** AI & LLM
- **Endpoint:** `https://api.anthropic.com/v1/messages`
- **Method:** `POST`
- **Auth:** `header` via `ANTHROPIC_API_KEY` (header `x-api-key`)
- **Docs:** https://docs.anthropic.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 anthropic-claude-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 anthropic-claude-api.py --smoke

# 3) Send a real request
export ANTHROPIC_API_KEY="your-key"
python3 anthropic-claude-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
