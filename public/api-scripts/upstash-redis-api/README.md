# Upstash Redis API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Upstash
- **Category:** Databases
- **Endpoint:** `https://{endpoint}.upstash.io`
- **Method:** `GET`
- **Auth:** `bearer` via `UPSTASH_REDIS_REST_TOKEN`
- **Docs:** https://upstash.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 upstash-redis-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 upstash-redis-api.py --smoke

# 3) Send a real request
export UPSTASH_REDIS_REST_TOKEN="your-key"
python3 upstash-redis-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
