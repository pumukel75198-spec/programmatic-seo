# Cloudflare Workers API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Cloudflare
- **Category:** Edge Computing
- **Endpoint:** `https://api.cloudflare.com/client/v4`
- **Method:** `GET`
- **Auth:** `bearer` via `CLOUDFLARE_API_KEY`
- **Docs:** https://developers.cloudflare.com/workers/

## Quick start

```bash
# 1) Inspect the request (no network)
python3 cloudflare-workers-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 cloudflare-workers-api.py --smoke

# 3) Send a real request
export CLOUDFLARE_API_KEY="your-key"
python3 cloudflare-workers-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
