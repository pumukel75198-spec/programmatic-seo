# Amazon Rekognition API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Amazon Web Services
- **Category:** AI & Vision
- **Endpoint:** `https://rekognition.us-west-2.amazonaws.com`
- **Method:** `GET`
- **Auth:** `aws-sigv4` via `AWS_ACCESS_KEY_ID`
- **Docs:** https://docs.aws.amazon.com/rekognition/latest/dg/what-is.html

## Quick start

```bash
# 1) Inspect the request (no network)
python3 aws-rekognition-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 aws-rekognition-api.py --smoke

# 3) Send a real request
export AWS_ACCESS_KEY_ID="your-key"
python3 aws-rekognition-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- This API needs request signing (AWS SigV4 / Digest). Use the official SDK for production calls.
- Requires AWS Signature Version 4. Use the official AWS SDK for --live.
