# GitHub REST API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** GitHub
- **Category:** Developer Tools
- **Endpoint:** `https://api.github.com/repos/{owner}/{repo}/issues`
- **Method:** `GET`
- **Auth:** `bearer` via `GITHUB_API_KEY`
- **Docs:** https://docs.github.com/en/rest

## Quick start

```bash
# 1) Inspect the request (no network)
python3 github-rest-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 github-rest-api.py --smoke

# 3) Send a real request
export GITHUB_API_KEY="your-key"
python3 github-rest-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
