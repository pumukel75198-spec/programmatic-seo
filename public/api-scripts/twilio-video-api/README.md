# Twilio Video API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Twilio
- **Category:** Communication
- **Endpoint:** `https://video.twilio.com/v1`
- **Method:** `GET`
- **Auth:** `bearer` via `TWILIO_API_KEY`
- **Docs:** https://www.twilio.com/docs/video

## Quick start

```bash
# 1) Inspect the request (no network)
python3 twilio-video-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 twilio-video-api.py --smoke

# 3) Send a real request
export TWILIO_API_KEY="your-key"
python3 twilio-video-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
