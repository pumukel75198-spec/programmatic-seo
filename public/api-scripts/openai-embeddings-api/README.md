# OpenAI Embeddings API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** OpenAI
- **Category:** AI & Embeddings
- **Endpoint:** `https://api.openai.com/v1/embeddings`
- **Method:** `POST`
- **Auth:** `bearer` via `OPENAI_API_KEY`
- **Docs:** https://platform.openai.com/docs/api-reference/embeddings

## Quick start

```bash
# 1) Inspect the request (no network)
python3 openai-embeddings-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 openai-embeddings-api.py --smoke

# 3) Send a real request
export OPENAI_API_KEY="your-key"
python3 openai-embeddings-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
