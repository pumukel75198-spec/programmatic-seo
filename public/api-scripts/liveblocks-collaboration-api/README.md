# Liveblocks Collaboration API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Liveblocks
- **Category:** Realtime
- **Endpoint:** `https://api.liveblocks.io/v2/rooms`
- **Method:** `GET`
- **Auth:** `bearer` via `LIVEBLOCKS_SECRET_KEY`
- **Docs:** https://liveblocks.io

## Quick start

```bash
# 1) Inspect the request (no network)
python3 liveblocks-collaboration-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 liveblocks-collaboration-api.py --smoke

# 3) Send a real request
export LIVEBLOCKS_SECRET_KEY="your-key"
python3 liveblocks-collaboration-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
