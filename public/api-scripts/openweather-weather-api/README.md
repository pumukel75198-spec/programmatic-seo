# OpenWeather Weather API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** OpenWeather
- **Category:** Weather
- **Endpoint:** `https://api.openweathermap.org/data/2.5/weather`
- **Method:** `GET`
- **Auth:** `query` via `OPENWEATHER_API_KEY`
- **Docs:** https://openweathermap.org/api

## Quick start

```bash
# 1) Inspect the request (no network)
python3 openweather-weather-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 openweather-weather-api.py --smoke

# 3) Send a real request
export OPENWEATHER_API_KEY="your-key"
python3 openweather-weather-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
