# Twitch API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Twitch
- **Category:** Communication
- **Endpoint:** `https://api.twitch.tv/helix`
- **Method:** `GET`
- **Auth:** `bearer` via `TWITCH_API_KEY`
- **Docs:** https://dev.twitch.tv/docs/api

## Quick start

```bash
# 1) Inspect the request (no network)
python3 twitch-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 twitch-api.py --smoke

# 3) Send a real request
export TWITCH_API_KEY="your-key"
python3 twitch-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
