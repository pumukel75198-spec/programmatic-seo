# Auth0 Authentication API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Auth0
- **Category:** Auth & Identity
- **Endpoint:** `https://{domain}/oauth/token`
- **Method:** `POST`
- **Auth:** `bearer` via `AUTH0_CLIENT_SECRET`
- **Docs:** https://auth0.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 auth0-authentication-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 auth0-authentication-api.py --smoke

# 3) Send a real request
export AUTH0_CLIENT_SECRET="your-key"
python3 auth0-authentication-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
