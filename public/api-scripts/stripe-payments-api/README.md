# Stripe Payments API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Stripe
- **Category:** Finance
- **Endpoint:** `https://api.stripe.com/v1`
- **Method:** `GET`
- **Auth:** `bearer` via `STRIPE_API_KEY`
- **Docs:** https://stripe.com/docs/api

## Quick start

```bash
# 1) Inspect the request (no network)
python3 stripe-payments-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 stripe-payments-api.py --smoke

# 3) Send a real request
export STRIPE_API_KEY="your-key"
python3 stripe-payments-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
