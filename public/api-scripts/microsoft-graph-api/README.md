# Microsoft Graph API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Microsoft
- **Category:** Developer Tools
- **Endpoint:** `https://graph.microsoft.com/v1.0`
- **Method:** `GET`
- **Auth:** `bearer` via `MICROSOFT_API_KEY`
- **Docs:** https://docs.microsoft.com/en-us/graph/api/overview

## Quick start

```bash
# 1) Inspect the request (no network)
python3 microsoft-graph-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 microsoft-graph-api.py --smoke

# 3) Send a real request
export MICROSOFT_API_KEY="your-key"
python3 microsoft-graph-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
