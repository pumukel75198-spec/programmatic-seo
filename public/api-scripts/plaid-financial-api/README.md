# Plaid Financial Data API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Plaid
- **Category:** Finance
- **Endpoint:** `https://production.plaid.com`
- **Method:** `POST`
- **Auth:** `header` via `PLAID_CLIENT_ID` (header `PLAID-CLIENT-ID`)
- **Docs:** https://plaid.com/docs/

## Quick start

```bash
# 1) Inspect the request (no network)
python3 plaid-financial-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 plaid-financial-api.py --smoke

# 3) Send a real request
export PLAID_CLIENT_ID="your-key"
python3 plaid-financial-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- Plaid also requires a PLAID-SECRET header. Add it in the script or use the official SDK.
