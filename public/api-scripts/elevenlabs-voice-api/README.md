# ElevenLabs Voice API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** ElevenLabs
- **Category:** AI & Voice
- **Endpoint:** `https://api.elevenlabs.io/v1/voices`
- **Method:** `GET`
- **Auth:** `header` via `ELEVENLABS_API_KEY` (header `xi-api-key`)
- **Docs:** https://elevenlabs.io

## Quick start

```bash
# 1) Inspect the request (no network)
python3 elevenlabs-voice-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 elevenlabs-voice-api.py --smoke

# 3) Send a real request
export ELEVENLABS_API_KEY="your-key"
python3 elevenlabs-voice-api.py --live --data '{"example":"value"}'
```
