Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Shopify
- **Category:** E-commerce
- **Endpoint:** `https://{shop}.myshopify.com/admin/api/2024-10/graphql.json`
- **Method:** `POST`
- **Auth:** `header` via `SHOPIFY_ACCESS_TOKEN` (header `X-Shopify-Access-Token`)
- **Docs:** https://shopify.dev/docs/api/admin

## Quick start

```bash
# 1) Inspect the request (no network)
python3 shopify-admin-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 shopify-admin-api.py --smoke

# 3) Send a real request
export SHOPIFY_ACCESS_TOKEN="your-key"
python3 shopify-admin-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
