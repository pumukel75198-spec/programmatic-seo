# Qdrant Vector API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Qdrant
- **Category:** Vector Database
- **Endpoint:** `https://api.cloud.qdrant.io`
- **Method:** `GET`
- **Auth:** `header` via `QDRANT_API_KEY` (header `api-key`)
- **Docs:** https://qdrant.tech

## Quick start

```bash
# 1) Inspect the request (no network)
python3 qdrant-vector-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 qdrant-vector-api.py --smoke

# 3) Send a real request
export QDRANT_API_KEY="your-key"
python3 qdrant-vector-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
