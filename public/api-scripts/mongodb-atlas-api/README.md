# MongoDB Atlas API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** MongoDB
- **Category:** Databases
- **Endpoint:** `https://cloud.mongodb.com/api/atlas/v1.0`
- **Method:** `GET`
- **Auth:** `digest` via `MONGODB_ATLAS_PUBLIC_KEY`
- **Docs:** https://www.mongodb.com/atlas

## Quick start

```bash
# 1) Inspect the request (no network)
python3 mongodb-atlas-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 mongodb-atlas-api.py --smoke

# 3) Send a real request
export MONGODB_ATLAS_PUBLIC_KEY="your-key"
python3 mongodb-atlas-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- This API needs request signing (AWS SigV4 / Digest). Use the official SDK for production calls.
