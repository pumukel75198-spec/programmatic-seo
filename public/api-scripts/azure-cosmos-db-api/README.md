# Microsoft Azure Cosmos DB API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Microsoft
- **Category:** Databases
- **Endpoint:** `https://{account}.documents.azure.com`
- **Method:** `GET`
- **Auth:** `header` via `AZURE_COSMOS_KEY` (header `Authorization`)
- **Docs:** https://docs.microsoft.com/en-us/azure/cosmos-db/

## Quick start

```bash
# 1) Inspect the request (no network)
python3 azure-cosmos-db-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 azure-cosmos-db-api.py --smoke

# 3) Send a real request
export AZURE_COSMOS_KEY="your-key"
python3 azure-cosmos-db-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
