# Mapbox Maps API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Mapbox
- **Category:** Geodata
- **Endpoint:** `https://api.mapbox.com`
- **Method:** `GET`
- **Auth:** `query` via `MAPBOX_ACCESS_TOKEN`
- **Docs:** https://docs.mapbox.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 mapbox-maps-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 mapbox-maps-api.py --smoke

# 3) Send a real request
export MAPBOX_ACCESS_TOKEN="your-key"
python3 mapbox-maps-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
