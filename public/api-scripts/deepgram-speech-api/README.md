# Deepgram Speech API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Deepgram
- **Category:** AI & Speech
- **Endpoint:** `https://api.deepgram.com/v1/projects`
- **Method:** `GET`
- **Auth:** `token` via `DEEPGRAM_API_KEY`
- **Docs:** https://deepgram.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 deepgram-speech-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 deepgram-speech-api.py --smoke

# 3) Send a real request
export DEEPGRAM_API_KEY="your-key"
python3 deepgram-speech-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
