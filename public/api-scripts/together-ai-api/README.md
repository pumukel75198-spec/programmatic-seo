# Together AI API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Together AI
- **Category:** AI & LLM
- **Endpoint:** `https://api.together.xyz/v1/models`
- **Method:** `GET`
- **Auth:** `bearer` via `TOGETHER_API_KEY`
- **Docs:** https://www.together.ai

## Quick start

```bash
# 1) Inspect the request (no network)
python3 together-ai-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 together-ai-api.py --smoke

# 3) Send a real request
export TOGETHER_API_KEY="your-key"
python3 together-ai-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
