Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Algolia
- **Category:** Search

- **Method:** `GET`
- **Auth:** `header` via `ALGOLIA_API_KEY` (header `X-Algolia-API-Key`)
- **Docs:** https://www.algolia.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 algolia-search-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 algolia-search-api.py --smoke

# 3) Send a real request
export ALGOLIA_API_KEY="your-key"
python3 algolia-search-api.py --live --data '{"example":"value"}'
```

## Notes

- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
