# Cohere Embed API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Cohere
- **Category:** AI & Embeddings
- **Endpoint:** `https://api.cohere.com/v2/embed`
- **Method:** `POST`
- **Auth:** `bearer` via `COHERE_API_KEY`
- **Docs:** https://cohere.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 cohere-embed-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 cohere-embed-api.py --smoke

# 3) Send a real request
export COHERE_API_KEY="your-key"
python3 cohere-embed-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
