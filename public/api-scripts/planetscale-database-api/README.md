# PlanetScale Database API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** PlanetScale
- **Category:** Databases
- **Endpoint:** `https://api.planetscale.com/v1/organizations`
- **Method:** `GET`
- **Auth:** `bearer` via `PLANETSCALE_API_TOKEN`
- **Docs:** https://planetscale.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 planetscale-database-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 planetscale-database-api.py --smoke

# 3) Send a real request
export PLANETSCALE_API_TOKEN="your-key"
python3 planetscale-database-api.py --live --data '{"example":"value"}'
```
