# Slack Web API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Slack
- **Category:** Communication
- **Endpoint:** `https://slack.com/api/chat.postMessage`
- **Method:** `POST`
- **Auth:** `bot` via `SLACK_API_KEY`
- **Docs:** https://api.slack.com/methods

## Quick start

```bash
# 1) Inspect the request (no network)
python3 slack-web-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 slack-web-api.py --smoke

# 3) Send a real request
export SLACK_API_KEY="your-key"
python3 slack-web-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
