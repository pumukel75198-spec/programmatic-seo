# SendGrid Email API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Twilio SendGrid
- **Category:** Communication
- **Endpoint:** `https://api.sendgrid.com/v3/mail/send`
- **Method:** `POST`
- **Auth:** `bearer` via `SENDGRID_API_KEY`
- **Docs:** https://sendgrid.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 sendgrid-email-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 sendgrid-email-api.py --smoke

# 3) Send a real request
export SENDGRID_API_KEY="your-key"
python3 sendgrid-email-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
