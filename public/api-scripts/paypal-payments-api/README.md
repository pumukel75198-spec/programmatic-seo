# PayPal Payments API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** PayPal
- **Category:** Payments
- **Endpoint:** `https://api.paypal.com/v1`
- **Method:** `GET`
- **Auth:** `bearer` via `PAYPAL_API_KEY`
- **Docs:** https://developer.paypal.com/docs/api/overview

## Quick start

```bash
# 1) Inspect the request (no network)
python3 paypal-payments-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 paypal-payments-api.py --smoke

# 3) Send a real request
export PAYPAL_API_KEY="your-key"
python3 paypal-payments-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
