Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** IBM

- **Method:** `GET`
- **Auth:** `bearer` via `IBM_API_KEY`
- **Docs:** https://cloud.ibm.com/apidocs/language-translator

## Quick start

```bash
# 1) Inspect the request (no network)
python3 ibm-watson-language-translator-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 ibm-watson-language-translator-api.py --smoke

# 3) Send a real request
export IBM_API_KEY="your-key"
python3 ibm-watson-language-translator-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
- Use the regional service URL from your IBM Cloud instance. IBM has retired some legacy hosts, so the exact host depends on your account.
