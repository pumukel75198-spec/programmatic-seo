# Google Sheets API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Google
- **Category:** Productivity & Data
- **Endpoint:** `https://sheets.googleapis.com/v4/spreadsheets/{spreadsheetId}`
- **Method:** `GET`
- **Auth:** `bearer` via `GOOGLE_API_KEY`
- **Docs:** https://developers.google.com/sheets/api/reference/rest

## Quick start

```bash
# 1) Inspect the request (no network)
python3 google-sheets-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 google-sheets-api.py --smoke

# 3) Send a real request
export GOOGLE_API_KEY="your-key"
python3 google-sheets-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
