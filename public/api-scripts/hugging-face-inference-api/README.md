# Hugging Face Inference API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Hugging Face
- **Category:** AI & ML
- **Endpoint:** `https://router.huggingface.co/v1/chat/completions`
- **Method:** `POST`
- **Auth:** `bearer` via `HUGGINGFACE_API_KEY`
- **Docs:** https://huggingface.co/inference-api

## Quick start

```bash
# 1) Inspect the request (no network)
python3 hugging-face-inference-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 hugging-face-inference-api.py --smoke

# 3) Send a real request
export HUGGINGFACE_API_KEY="your-key"
python3 hugging-face-inference-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
