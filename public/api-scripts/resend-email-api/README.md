# Resend Email API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Resend
- **Category:** Communication
- **Endpoint:** `https://api.resend.com/emails`
- **Method:** `POST`
- **Auth:** `bearer` via `RESEND_API_KEY`
- **Docs:** https://resend.com/docs

## Quick start

```bash
# 1) Inspect the request (no network)
python3 resend-email-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 resend-email-api.py --smoke

# 3) Send a real request
export RESEND_API_KEY="your-key"
python3 resend-email-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
