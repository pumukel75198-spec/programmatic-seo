# Vercel Blob API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Vercel
- **Category:** Storage
- **Endpoint:** `https://blob.vercel-storage.com`
- **Method:** `GET`
- **Auth:** `bearer` via `BLOB_READ_WRITE_TOKEN`
- **Docs:** https://vercel.com/docs/storage/vercel-blob

## Quick start

```bash
# 1) Inspect the request (no network)
python3 vercel-blob-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 vercel-blob-api.py --smoke

# 3) Send a real request
export BLOB_READ_WRITE_TOKEN="your-key"
python3 vercel-blob-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
