# Doppler Secrets API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Doppler
- **Category:** Security
- **Endpoint:** `https://api.doppler.com/v3/configs`
- **Method:** `GET`
- **Auth:** `bearer` via `DOPPLER_API_KEY`
- **Docs:** https://www.doppler.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 doppler-secrets-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 doppler-secrets-api.py --smoke

# 3) Send a real request
export DOPPLER_API_KEY="your-key"
python3 doppler-secrets-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
