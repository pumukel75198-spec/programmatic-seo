# Clerk Authentication API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Clerk
- **Category:** Auth & Identity
- **Endpoint:** `https://api.clerk.com/v1`
- **Method:** `GET`
- **Auth:** `bearer` via `CLERK_API_KEY`
- **Docs:** https://clerk.com/docs

## Quick start

```bash
# 1) Inspect the request (no network)
python3 clerk-authentication-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 clerk-authentication-api.py --smoke

# 3) Send a real request
export CLERK_API_KEY="your-key"
python3 clerk-authentication-api.py --live --data '{"example":"value"}'
```

- Requires Python 3.8+ and only uses the standard library.
