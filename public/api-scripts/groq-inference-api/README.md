# Groq Inference API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Groq
- **Category:** AI & Inference
- **Endpoint:** `https://api.groq.com/openai/v1/models`
- **Method:** `GET`
- **Auth:** `bearer` via `GROQ_API_KEY`
- **Docs:** https://groq.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 groq-inference-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 groq-inference-api.py --smoke

# 3) Send a real request
export GROQ_API_KEY="your-key"
python3 groq-inference-api.py --live --data '{"example":"value"}'
```
