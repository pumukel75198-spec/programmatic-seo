# Telegram Bot API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Telegram
- **Category:** Messaging
- **Endpoint:** `https://api.telegram.org/bot{token}/sendMessage`
- **Method:** `GET`
- **Auth:** `url-token` via `TELEGRAM_BOT_TOKEN`
- **Docs:** https://core.telegram.org/bots/api

## Quick start

```bash
# 1) Inspect the request (no network)
python3 telegram-bot-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 telegram-bot-api.py --smoke

# 3) Send a real request
export TELEGRAM_BOT_TOKEN="your-key"
python3 telegram-bot-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
- The endpoint contains placeholders (e.g. `{...}`). Replace them before using `--live`.
