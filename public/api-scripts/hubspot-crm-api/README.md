## Quick start

```bash

python3 hubspot-crm-api.py --dry-run

python3 hubspot-crm-api.py --smoke

# 3) Send a real request
export HUBSPOT_API_KEY="your-key"
python3 hubspot-crm-api.py --live --data '{"example":"value"}'
```
