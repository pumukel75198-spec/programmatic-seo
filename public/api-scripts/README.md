# API Starter Scripts

This directory contains 75 auto-generated Python starter scripts, one per API listed on [FlowMatrix.dev](https://flowmatrix.dev).

- Scripts with a reachable endpoint: **58**
- Scripts requiring manual endpoint setup: **17**

Each folder contains the script, a README and metadata:

```
api-scripts/<slug>/<slug>.py
api-scripts/<slug>/README.md
api-scripts/<slug>/metadata.json
```

Machine-readable manifest: [`index.json`](./index.json).

Regenerate with `npm run api-scripts:generate` and verify with `npm run api-scripts:test`.
