# PostHog Analytics API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** PostHog
- **Category:** Analytics
- **Endpoint:** `https://us.posthog.com/api/projects/`
- **Method:** `GET`
- **Auth:** `bearer` via `POSTHOG_API_KEY`
- **Docs:** https://posthog.com

## Quick start

```bash
# 1) Inspect the request (no network)
python3 posthog-analytics-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 posthog-analytics-api.py --smoke

# 3) Send a real request
export POSTHOG_API_KEY="your-key"
python3 posthog-analytics-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
