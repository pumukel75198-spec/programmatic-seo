# IBM Cloud Object Storage API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** IBM
- **Category:** Storage
- **Endpoint:** `https://s3.us.cloud-object-storage.appdomain.cloud`
- **Method:** `GET`
- **Auth:** `bearer` via `IBM_API_KEY`
- **Docs:** https://cloud.ibm.com/docs/cloud-object-storage

## Quick start

```bash
# 1) Inspect the request (no network)
python3 ibm-cloud-object-storage-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 ibm-cloud-object-storage-api.py --smoke

# 3) Send a real request
export IBM_API_KEY="your-key"
python3 ibm-cloud-object-storage-api.py --live --data '{"example":"value"}'
```

- Requires Python 3.8+ and only uses the standard library.
