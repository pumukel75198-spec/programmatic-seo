# Stability AI Image API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Stability AI
- **Category:** AI & Image
- **Endpoint:** `https://api.stability.ai/v1/user/account`
- **Method:** `GET`
- **Auth:** `bearer` via `STABILITY_API_KEY`
- **Docs:** https://stability.ai

## Quick start

```bash
# 1) Inspect the request (no network)
python3 stability-ai-image-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 stability-ai-image-api.py --smoke

# 3) Send a real request
export STABILITY_API_KEY="your-key"
python3 stability-ai-image-api.py --live --data '{"example":"value"}'
```
