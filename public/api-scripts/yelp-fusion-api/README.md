# Yelp Fusion API – Starter Script

Generated by [FlowMatrix.dev](https://flowmatrix.dev). A minimal, dependency-free Python client.

- **Provider:** Yelp
- **Category:** Geodata
- **Endpoint:** `https://api.yelp.com/v3`
- **Method:** `GET`
- **Auth:** `bearer` via `YELP_API_KEY`
- **Docs:** https://www.yelp.com/developers/documentation/v3

## Quick start

```bash
# 1) Inspect the request (no network)
python3 yelp-fusion-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 yelp-fusion-api.py --smoke

# 3) Send a real request
export YELP_API_KEY="your-key"
python3 yelp-fusion-api.py --live --data '{"example":"value"}'
```

## Notes

- Requires Python 3.8+ and only uses the standard library.
