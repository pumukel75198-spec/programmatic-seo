## Quick start

```bash
# 1) Inspect the request (no network)
python3 replicate-model-api.py --dry-run

# 2) Check that the endpoint is reachable (no key needed)
python3 replicate-model-api.py --smoke

# 3) Send a real request
export REPLICATE_API_TOKEN="your-key"
python3 replicate-model-api.py --live --data '{"example":"value"}'
```
