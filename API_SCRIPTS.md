# API Starter Scripts

Every API listed on [flowmatrix.dev](https://flowmatrix.dev) ships with a
downloadable, **dependency-free** Python script. Scripts are generated by the
Unified Pipeline ([`pipeline/run_batch.py`](pipeline/run_batch.py)) from
[`src/data/apis.json`](src/data/apis.json) and stored in `private/api-scripts/`.

## What gets generated

For each API (`<slug>`):

```
private/api-scripts/<slug>/<slug>.py      production-ready script
private/api-scripts/<slug>/README.md      short usage guide
private/api-scripts/<slug>/metadata.json  machine-readable metadata
```

## Binding script standard

- **100 % Python standard library** (`urllib.request`, `urllib.error`, `json`,
  `os`, `sys`, `time`, `hmac`, `hashlib`, `base64`, `typing`, `logging`, …).
  Third-party imports (`requests`, `openai`, `supabase`, `httpx`, `aiohttp`,
  `pydantic`, `sentry_sdk`, …) are rejected by the AST gatekeeper.
- Configuration via `os.environ.get("..._API_KEY")`; keys are never hardcoded.
- A robust `request_json(...)` helper with timeout, auth headers,
  `HTTPError`/`URLError` handling and exponential backoff on `429`/`5xx`.
- **2–3 end-to-end functions** with type hints and docstrings.
- An executable `if __name__ == "__main__":` demonstration.
- Mock execution must pass (no `NameError`/`TypeError`/`KeyError`/`AttributeError`).

## Generate / validate

```bash
# Regenerate a single script through the pipeline
.venv/bin/python -m pipeline.run_batch --only-api sentry-performance-api \
  --skip-build --skip-upload --skip-deploy

# Regenerate N scripts
.venv/bin/python -m pipeline.run_batch --apis 4 --skip-build --skip-upload --skip-deploy
```

The pipeline validates each script before writing it. Invalid scripts are
discarded after 3 self-healing attempts.

## Adding or fixing an endpoint

`src/data/apis.json` is the source of truth. Add overrides in
[`src/data/api-endpoints.json`](src/data/api-endpoints.json):

```json
{
  "my-api-slug": {
    "endpoint": "https://api.example.com/v1/things",
    "method": "GET",
    "auth": "bearer",
    "keyEnv": "EXAMPLE_API_KEY"
  }
}
```

Endpoints with placeholders (`{...}` or `<...>`) are generated but skipped by
the live domain check, because the real host/value depends on the user's account.

## Security

- Secrets are never written to generated files.
- The mock execution uses fake environment values and a patched `urlopen`.
- Nothing is uploaded to R2 or deployed unless the validator passes.
